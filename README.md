# Python [ Ciência e Análise de Dados ] 

Repositório com o objetivo de dar visibilidade a habilidades em linguagem Python em 3 campos: **Análise de Dados**, **Geração de Insights** e **Automação de Tarefas**.
Cada pasta deste repositório traz um trabalho voltado a um desses temas.

Entre as bibliotecas mais utilizadas: **Selenium** para automação em ambiente web, **Regex** para captura de padrões em documentos, **Pandas** para análise de dados, **Scikit-Learn**, **XGBoost** e **LightGBM** para modelos preditivos, **SHAP** para explicar as previsões dos modelos, entre outras.

**Modelos disponíveis:**<br>
- [Case: Financeira - Análise de Risco](analise_dados/README.md) [Agrupamento, Classificação, Métricas]
- [Case: Seguradora - Triagem de Sinistros Suspeitos de Fraude](Data%20Science_Classification/README.md) [Dummy, DecisionTree, RandomForest, XGBoost, LightGBM][SHAP, Análise Custo] — score de suspeita para priorizar a fila de perícia: **−49% no custo mensal com a mesma equipe** e **5,4× mais fraudes encontradas** que a política atual (dados sintéticos)
